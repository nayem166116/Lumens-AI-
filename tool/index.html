How this is scored

The clarity score checks for a greeting, a stated identity, a stated reason for calling, and a request for permission to continue — the same four elements Lumens checks on live calls in production, applied here to whatever you paste.

This is a simplified, browser-only version of the scoring model. The full product also checks tone, pacing, and required regulatory disclosures against your organization’s specific script library.
